# Changelog

## [1.0.0] - 2026-09-30

First release.

- Saw/square oscillator into an oversampled diode-ladder style resonant filter
- Filter envelope (Env Mod, Decay), accent with accent build-up, slide, drive
- MIDI mode: velocity 100+ accents, overlapping notes slide
- Host-synced 16-step sequencer with per-step note, octave, gate, accent and slide; swing, gate length, root note, pattern length, random/clear/shift
- Knob shortcuts: double-click/Alt-click reset, Ctrl/Shift fine drag, type-in values, centre detent on Tune
- VST3 and Standalone for Windows 64-bit
